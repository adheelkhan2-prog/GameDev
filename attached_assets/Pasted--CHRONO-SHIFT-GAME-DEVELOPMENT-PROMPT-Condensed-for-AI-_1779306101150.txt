## GAME CONCEPT: "CHRONO SHIFT"

**Genre:** Action-Puzzle 2D Platformer with Time Mechanics

**Story:** A temporal scientist gets trapped in a fractured timeline. Collect Chrono-Crystals across 3 levels using time-manipulation powers to restore reality.

**Core Unique Feature:** Players control a character with TWO special time-bending abilities not found in typical games.

---

## MUST-HAVE MECHANICS

### 1. **Time Slow Ability** (Press E)
- Slows all objects/enemies to 20% speed (player moves normal speed)
- Duration: 5 seconds | Cooldown: 3 seconds
- Visual effect: Blue tint overlay + time distortion particles
- Purpose: Navigate fast obstacles, dodge enemies

### 2. **Time Rewind Ability** (Press R)
- Rewinds non-player objects backwards 2 seconds
- Shows "ghost trail" of rewound positions
- Objects keep their velocity after rewind (enables puzzle solutions)
- Duration: 2 seconds | Cooldown: 4 seconds
- Purpose: Reset enemy patterns, solve time-based puzzles

### 3. **Standard Platformer Mechanics**
- Smooth left/right movement (Arrow Keys or A/D)
- Jump with gravity (Space bar)
- Collision detection (platforms, enemies, hazards)
- Health system (lose 1 HP on enemy contact, knockback effect)

---

## GAME CONTENT

### Player Character
- Bright cyan sprite with glowing effect
- Smooth animations (idle, run, jump, fall, damage)
- Respawns at level start on death

### Collectibles (Per Level: 5 each)
- **Chrono-Crystals:** Golden glowing objects. Collect all 5 to unlock level exit
- **Time Shards:** Bonus items for points, can restore ability cooldowns
- **Health Pickups:** Restore 1 HP

### Enemies (3 Types)
1. **Temporal Drones:** Patrol in patterns, slow-moving, can be rewound
2. **Phase Shifters:** Randomly teleport, affected by time slow
3. **Pulsars:** Stationary, shoot projectiles in rhythm patterns

### Environmental Hazards
- **Spike Traps:** Instant kill (1 hit KO)
- **Time Vortexes:** Zones where abilities work differently
- **Collapsing Platforms:** Disappear 3 seconds after landing, respawn

### Three Levels (Progressive Difficulty)

**Level 1 - "Temporal Starting Ground"** (Tutorial)
- Easy, spacious layouts
- 1-2 slow enemies
- Introduces mechanics gradually
- Basic platforms, clear paths

**Level 2 - "The Fractured Zone"** (Intermediate)
- Complex platform arrangements
- Multiple Phase Shifters (teleporting enemies)
- Time Rewind becomes critical mechanic
- One "Time Vortex" zone

**Level 3 - "Temporal Apex"** (Hard)
- Tight platform navigation
- Multiple simultaneous Pulsars
- Collapsing platforms
- Requires creative ability combinations
- Final boss gauntlet section

## KEY CODE PATTERNS

### Time Slow Implementation
```javascript
activateTimeSlow() {
  if (!this.timeslowReady) return;
  this.scene.time.timeScale = 0.2; // Slow to 20%
  this.timeslowReady = false;
  
  // After 5 seconds, restore and start cooldown
  this.scene.time.delayedCall(5000, () => {
    this.scene.time.timeScale = 1;
    // 3 second cooldown
    this.scene.time.delayedCall(3000, () => {
      this.timeslowReady = true;
    });
  });
}
```

### Time Rewind Recording
```javascript
// Every frame, store positions
update() {
  this.positionHistory.push({
    x: this.x,
    y: this.y,
    velocityX: this.body.velocity.x,
    velocityY: this.body.velocity.y,
    timestamp: this.scene.time.now
  });
  
  // Keep only last 2 seconds of history
  if (this.positionHistory.length > 120) {
    this.positionHistory.shift();
  }
}

// Play back in reverse
rewind() {
  const history = this.positionHistory.reverse();
  let index = 0;
  
  const rewindTimer = setInterval(() => {
    if (index < history.length) {
      const state = history[index];
      this.x = state.x;
      this.y = state.y;
      index++;
    } else {
      // Restore original velocity after rewind
      this.body.velocity.set(state.velocityX, state.velocityY);
      clearInterval(rewindTimer);
    }
  }, 16); // ~60 FPS
}
```
